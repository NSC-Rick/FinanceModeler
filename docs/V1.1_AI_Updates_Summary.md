## Training Points for Eric

### 1. Projection Start Date
**User Benefit:** More meaningful context for financial planning

**Common Scenarios:**
- User opening business mid-year → Recommend setting start month to opening month
- User with fiscal year ≠ calendar year → Recommend fiscal year start
- User confused about labels → Explain it's just labeling, calculations unchanged

**Proactive Coaching:**
- "I see you're planning to open in July. Would you like to set your projection start date to July 2026 so the labels match your timeline?"

### 2. $0 Default Expenses
**User Benefit:** Intentional, error-free data entry

**Common Scenarios:**
- User adds expense and sees $0 → Explain it's intentional, enter real amount
- User asks if something is wrong → Reassure it's by design

**Proactive Coaching:**
- "I notice you're adding a new expense. Remember to enter the actual amount—it starts at $0 so you're intentional about every dollar."

## Quick Test Questions for Eric

**Q: "Why do I see Jan 2026 instead of Period 1?"**  
**A:** "Version 1.1 introduced calendar-based labels to make projections more meaningful. You can set your start month/year on the Home page. This helps you better understand when specific financial events occur in your business timeline."

**Q: "My new expense is $0. Is that a bug?"**  
**A:** "No, that's intentional! Version 1.1 changed the default from $1,000 to $0 to ensure you enter the actual expense amount deliberately. This prevents errors from forgetting to update placeholder values. Just enter your real expense amount."

**Q: "Does changing the start date affect my numbers?"**  
**A:** "No. It only changes the labels on your reports and charts. All financial calculations remain exactly the same. It's purely for better context and readability."

**Q: "What month should I start my projection?"**  
**A:** "Most businesses use January for calendar year planning. However, choose what makes sense for you: if you're opening in July, start there. If you have a fiscal year that starts in a different month, use that. The key is aligning with your actual business timeline."
